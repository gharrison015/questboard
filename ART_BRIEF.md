# QuestBoard Mascot Art Brief

This is the single source of truth for QuestBoard mascot art. Every theme gets one hero mascot in the same look and feel so the app stays cohesive as you swipe between kids.

Each profile picks a theme. The theme owns a palette, a money word (fuel, stardust, treasure), and a mascot. The mascot is the personality of the profile, so the art quality is what makes it feel like a real app instead of a school worksheet.

## The Look (apply to every mascot)

- **Style:** Pixar / Disney-Pixar feature-film 3D render. Soft global illumination, gentle studio key light, warm bounce light, subtle ambient occlusion. Polished and toy-like, not flat vector, not cheap clip art.
- **Personality:** big expressive friendly eyes, a warm happy smile, cute and approachable. These are for kindergarten and first graders, so it must read as a lovable buddy, not scary or edgy.
- **Proportions:** slightly chibi (oversized head or oversized features), heroic confident pose.
- **Color:** vibrant and saturated, candy-bright. Each theme leads with its accent color (see table).
- **Framing:** single character, centered, full subject in frame with a little breathing room, three-quarter hero angle.
- **Background:** none. Solid bright green screen background for clean cutout (the pipeline keys it out to transparent PNG). If your tool supports transparent output directly, use that instead.
- **Clean output:** no text, no words, no logos, no watermark, no brand marks, no real trademarked characters. Original character inspired by the style only.

## Technical Settings

| Setting | Value |
|---|---|
| Format | PNG with transparent background |
| Size | 2K (about 2048 x 2048) so it stays crisp from phone to TV |
| Aspect | 1:1 square |
| Subject | one mascot, centered, full body in frame |
| Background | transparent (or solid green screen to key out) |

## How to Use the Output

1. Generate at 2K, transparent PNG, square.
2. Name the file `THEME_mascot.png` (for example `space_mascot.png`).
3. Drop it in `prototype/assets/`. The dashboard loads each profile's mascot from there.
4. If your generator gives a colored background, ask it to "make the background transparent" or generate on a solid green screen and key it out.

## Notes on Safety and Ownership

Keep every mascot an original character "inspired by" the Pixar look. Do not reproduce real named characters (no actual Monster Jam trucks, no Disney characters by name) and no real logos or brand marks. This keeps the art clean to use commercially if QuestBoard becomes a real product.
